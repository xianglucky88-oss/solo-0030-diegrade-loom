# 晶格分档台

把多批次探针记录合并到同一张晶圆格点图，逐颗追溯首测、复测与复核，再交付可复算的分选清单。浏览器界面由原生 HTML、CSS、JavaScript 构成；Python 后端通过 SQLite 保存现场记录，无第三方运行时依赖。

## 启动

在仓库根目录使用 Python 3.11+（SQLite 3.35+）：

```sh
python3 -B -m diegrade --demo
```

浏览器访问 `http://127.0.0.1:8736`。首次启动会写入 `.diegrade-data/station.sqlite3`。可用 `--db` 指定路径、`--port` 指定端口。该服务只监听本机，适合作为单机工作台；没有多人账号和公网部署功能。

1. 演示晶圆 `NX-07` 已收录首测 `P01`。选「定位待办」看开路证据。
2. 在「批次预检与导入」填写批次 `P02`，选「复测」，保持默认坐标系，选择 `examples/nx07-repeat.csv`。预检只列拟写入结果；再点导入。
3. 在「分选交付」签出当前版。可以下载分选表 CSV、证据包 JSON，并从封存规则和事实重新计算。
4. 在格点图选 `(0, -1)`，到「复核登记」填写复核编号与事由。该点进入待复测，新版不能签出，第 2 代仍可查阅。以 `P02` 为父批次提交一颗新的复测记录（如 `0,-1,ok,30,90,P02`），再签出第 4 代，比较两版。

## 输入和交付

- 规则和晶圆可以从「规则与晶圆」登记；物理行段格式为 `[y, x起, x止]`，端点均包含，允许同一行含多个不重叠行段。`reserved` 是不投测、也不进入分选表的物理格点。
- 批次 CSV 使用 `x,y,contact,leak_na,margin_mv,parent`，从设备格点坐标起算。镜像取 `x=-x`，再逆时针旋转，最后平移。`contact` 为 `ok` 或 `open`；`open` 必须留空两个测值。首测留空 `parent`，复测填当前格点的父批次号。
- 没有登记设备位姿的工位可在「装夹周期与标记」登记周期：固定所属晶圆、允许的旋转与镜像组合，以及各对准标记在物理掩模上的坐标。标记观测分次报送；全部观测须由同一平移解释同一朝向。可行朝向为零时提示观测不一致，多于一个时显示未确定并拒绝该周期的量测；恰好一个时确认并锁定，同一标记原样重送不增加证据，锁定后的冲突观测被拒。引用周期的批次只按锁定位姿归一，自带坐标系与锁定值冲突则拒绝来件。新装夹周期须独立确认；不用标记的旧批次仍可自带坐标系。
- 分选 CSV 为 `x,y,bin,batch`，按物理 `y`、`x` 升序输出，`bin` 为 `a`、`b` 或 `reject`。摘要用于内容一致性比对，不是数字签名。证据包记录各周期的配置、观测与确认时的原始标记，接收方可用 `POST /api/diegrade/verify` 独立复算各批次采用的位姿与归到的物理点，核验会拒绝被篡改位姿的包。

## 检查

```sh
python3 -B -m tools.build
python3 -B -m tools.smoke
python3 -B -m tools.check_cycle
python3 -B -m tools.check_legacy
```

构建检查用 Node.js 校验浏览器模块语法，不需要安装 npm 包。HTTP 演练使用临时目录和随机本地端口，不接触实际库；`check_cycle` 走 3×3 对准标记场景，`check_legacy` 覆盖旧库迁移、旧封存件与位姿伪造对照。独立自动化测试套件暂缓。
